Pre-Attack File Monitoring

Establish trusted SHA-256 cryptographic baselines before incident detonation and detect unauthorized file modifications or deletions.

Forensic Integrity Protocol: Baseline Proof vs. Unknown State
The system strictly distinguishes between a file verified against a trusted pre-attack baseline and an unbaselined file. If no trusted baseline exists prior to an incident, the system flags the target as Unknown Baseline and will never claim proof of tampering without original cryptographic reference.
